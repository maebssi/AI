# 이송설비 정비 안전작업 절차 (LOTO)

문서번호: MNT-SAF-008

## 1. 적용 범위
OHT·AGV의 전기·기계 정비 작업 전반.

## 2. 잠금·표지(LOTO) 절차
1. 작업 전 관제 시스템에서 대상 호기를 운행 제외(격리) 처리한다.
2. 주전원 차단기 OFF 후 개인 잠금장치와 '작업중' 표지를 부착한다.
3. 잔류 에너지 제거: 인버터 DC 링크 콘덴서 방전 대기(최소 5분), 호이스트 하중 해제, 배터리 커넥터 분리(AGV).
4. 검전기로 무전압 확인 후 작업을 시작한다.
5. 작업 완료 후 공구 회수, 작업자 전원 확인, 잠금 해제 순서로 복귀한다.

## 3. 추가 안전수칙
- OHT 정비는 고소작업이므로 안전대 착용, 2인 1조 작업.
- 과열 설비는 표면 온도가 50℃ 이하로 떨어진 후 접촉한다.
- 위험 단계 설비의 재가동은 정비 파트장 확인 후에만 가능하다.
