# AGV(무인 운반차) 예방정비 기준

문서번호: MNT-PM-007

## 1. 점검 주기
- 일일: 배터리 잔량·충전 상태, 비상정지 스위치 동작, 범퍼 센서 확인
- 주간: 구동 휠 마모, 브레이크 동작, 분진 센서 흡입구 청소
- 월간: 주행·리프트 모터 절연저항, 배터리 셀 전압 편차 확인
- 반기: 감속기 그리스 보충, 리프트 체인 장력 조정

## 2. 주요 소모품 교체 주기(가동일 기준)
- 구동 휠: 120일, 브레이크 패드: 180일, 배터리: 3년 또는 용량 80% 미만 시

## 3. AGV 특이사항
- AGV는 주행 모터(CT2 약 75A)와 리프트 모터(CT3 약 50A) 상시 부하가 크다.
- 열화 진행 시 온도·분진·전류가 함께 증가하는 경향이 있어 복합 신호로 판단한다.
- 정비 시 AGV를 정비 구역으로 수동 이동시키고, 관제 시스템에서 해당 호기를 '정비중'으로 전환하여 작업 할당을 막는다.
