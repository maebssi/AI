# 분진(미세먼지) 증가 진단 및 조치 가이드

문서번호: MNT-TRB-005

## 1. 증상
- PM1.0 / PM2.5 / PM10 농도가 정상 대비 30% 이상 상승(주로 AGV).
- AGV 기준 PM10 정상 약 48µg/m³ → 경고 약 81µg/m³, 위험 약 85µg/m³.

## 2. 의미
- 분진 증가는 브레이크 패드·구동 휠(우레탄) 마모, 벨트 마모의 간접 지표이다.
- 온도 상승과 동반되면 브레이크 끌림 가능성이 높다.
- OHT는 클린룸 구간을 주행하므로 분진 센서 변화가 거의 없으며, OHT에서 분진이 올라가면 주변 공정 환경 문제를 먼저 확인한다.

## 3. 조치
1. 브레이크 패드 두께 확인 (마모 한계 2mm).
2. 구동 휠 직경 측정 (신품 대비 3mm 이상 감소 시 교체).
3. 분진 센서 흡입구 청소 및 센서 교정.
4. 주행 경로 바닥 청소 상태 확인.

## 4. 관련 부품
- 브레이크 패드 (BRK-PAD-A), 구동 휠 (WHL-PU-150), 분진 센서 필터 (PM-FLT-01)
