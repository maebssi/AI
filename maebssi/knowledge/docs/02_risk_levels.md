# 설비 위험도 4단계 정의 및 대응 기준

문서번호: MNT-RSK-002

## 1. 단계 정의
- 0 정상(NORMAL): 모든 신호가 정상 범위 이내. 정기 점검 주기 유지.
- 1 관심(ATTENTION): 내부 온도 또는 열화상 최고온도가 정상 90백분위를 넘거나 상승 추세가 관찰됨. 전류는 대체로 정상. 모니터링 주기를 단축한다.
- 2 경고(WARNING): 열화상 최고온도가 OHT 약 74℃, AGV 약 89℃(경고 단계 중앙값) 수준에 도달하거나 특정 CT 전류가 평상시의 수 배 이상으로 증가. 계획 정비를 24시간 이내에 편성한다.
- 3 위험(DANGER): 열화상 최고온도 OHT 약 90℃, AGV 약 95℃ 이상, 주행 모터 전류(CT2)가 OHT 90A·AGV 180A 수준으로 급증. 즉시 운행을 중지하고 긴급 정비한다.

## 2. 단계별 대응 기준(SLA)
| 단계 | 조치 | 목표 착수 시간 | 승인자 |
|---|---|---|---|
| 정상 | 정기 점검 유지 | - | - |
| 관심 | 모니터링 주기 1분→10초, 다음 정기 점검 시 확인 | 72시간 | 설비 담당자 |
| 경고 | 계획 정비 작업지시 발행, 예비 부품 확보 | 24시간 | 정비 파트장 |
| 위험 | 해당 설비 운행 중지(격리), 긴급 작업지시 | 1시간 | 생산 관리자 + 정비 파트장 |

## 3. 에스컬레이션
- 같은 설비에서 경고가 30분 이상 지속되면 위험 단계에 준하여 대응한다.
- 같은 라인에서 2대 이상이 동시에 경고 이상이면 공통 원인(전원·환경)을 우선 점검한다.
- AI의 위험도 판정은 참고 정보이며, 운행 중지·작업지시 발행은 반드시 관리자 승인 후 실행한다.
