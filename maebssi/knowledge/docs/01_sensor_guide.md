# 이송장치 센서 구성 및 정상 범위 가이드

문서번호: MNT-SEN-001 / 대상 설비: OHT(천장 주행 반송장치) 01~18호기, AGV(무인 운반차) 01~18호기

## 1. 센서 구성
이송장치 1대에는 다음 센서가 장착되어 1초 주기로 값을 수집한다.
- NTC: 제어함 내부 온도 센서(℃). 모터 드라이버·배터리·제어보드 주변의 발열을 반영한다.
- PM1.0 / PM2.5 / PM10: 설비 내부 분진(미세먼지) 농도 센서(µg/m³). 브레이크·휠·벨트 마모 분진과 주변 환경 분진을 반영한다.
- CT1 ~ CT4: 전류 변환기(Current Transformer) 기반 과전류 센서(A). 구동 모터·주행 모터·호이스트(OHT) 등 주요 부하의 전류를 측정한다.
- 열화상 카메라: 120×160 해상도 온도 행렬(℃). 최고 온도(TGmx)와 그 위치(X_Tmax, Y_Tmax)를 함께 기록한다.
- 외부 환경: 주변 온도(ex_temperature), 습도(ex_humidity), 조도(ex_illuminance).

## 2. OHT 정상 범위 (정상 상태 학습 데이터 중앙값 / 90백분위)
- NTC 내부 온도: 중앙값 27.4℃, 90백분위 28.6℃. 30℃를 넘으면 관심 단계로 본다.
- CT1: 2.4A / 2.8A, CT2: 1.1A / 1.4A, CT3: 0.5A / 0.7A, CT4: 0.5A / 0.6A. OHT는 대기·저부하 운전 비중이 높아 전류가 낮다.
- PM10: 약 20µg/m³. OHT는 클린룸 천장 주행 구간이므로 분진 변화가 거의 없다.
- 열화상 최고 온도: 중앙값 46.6℃, 90백분위 50.9℃.

## 3. AGV 정상 범위 (정상 상태 학습 데이터 중앙값 / 90백분위)
- NTC 내부 온도: 중앙값 25.4℃, 90백분위 30.0℃.
- CT1: 1.9A / 2.1A, CT2: 74.9A / 75.1A, CT3: 50.0A / 50.0A, CT4: 19.9A / 20.0A. AGV는 주행 모터(CT2)와 리프트(CT3) 상시 부하가 크다.
- PM10: 중앙값 48µg/m³, 90백분위 51µg/m³. 바닥 주행으로 OHT보다 분진이 높다.
- 열화상 최고 온도: 중앙값 49.1℃, 90백분위 62.6℃.

## 4. 판독 시 유의사항
- 절대값보다 동일 설비의 최근 60초 이동평균 대비 편차와 30초 기울기(상승 추세)를 함께 본다.
- 외부 온도가 높은 날에는 NTC·열화상 값이 함께 올라가므로 '설비 온도 − 주변 온도' 차이로 판단한다.
- 단일 프레임의 튀는 값(스파이크)은 센서 노이즈일 수 있으므로 10초 이상 지속될 때 판정한다.
