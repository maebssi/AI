# OHT(천장 주행 반송장치) 예방정비 기준

문서번호: MNT-PM-006

## 1. 점검 주기
- 일일: 주행 이상음, 알람 이력, 열화상 최고온도 추이 확인
- 주간: 주행 휠·가이드 롤러 마모 확인, 호이스트 벨트 장력 확인
- 월간: 주행 모터 절연저항 측정, 제어함 냉각팬 청소, 커넥터 체결 확인
- 반기: 감속기 오일 교환, 호이스트 벨트 교체 검토

## 2. 주요 소모품 교체 주기(가동일 기준)
- 주행 휠: 180일, 가이드 롤러: 180일, 호이스트 벨트: 365일, 냉각팬: 730일

## 3. OHT 특이사항
- OHT는 누적 가동일이 길고(평균 설비 이력 13년 수준) 대기 운전이 많아 전류 절대값은 낮지만, 열화 시 CT2(주행) 전류가 수십 배로 급증하는 특성이 있다.
- 천장 레일 구간에서 정비하므로 정비 전 해당 구간 우회 경로(바이패스)를 설정하고 고소작업 안전수칙을 따른다.
